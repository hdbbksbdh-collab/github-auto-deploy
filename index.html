🚀 GitHub一键部署工具

简化您的GitHub项目部署流程

🎯 核心功能

📦

自动创建仓库

基于项目名称自动生成GitHub仓库，支持公开/私有仓库创建

🚀

一键部署

完整的Git操作流程：初始化→添加远程→提交→推送，无需手动操作

🌐

自动启用Pages

自动创建gh-pages分支、配置Pages服务，生成访问链接

👁️

浏览器预览

支持自动打开浏览器预览已部署的Pages应用

📋 使用方法

# 1. 克隆仓库
git clone https://github.com/hdbbksbdh-collab/github-auto-deploy.git
cd github-auto-deploy

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行部署工具
python github_deploy.py

# 4. 按照提示输入信息完成部署

🔧 配置说明

运行工具时需要提供以下信息：

  • GitHub用户名 - 您的GitHub账户名
  • Personal Access Token - 具有repo权限的访问令牌
  • 项目名称 - 要创建的GitHub仓库名称
  • 项目描述 - 仓库的描述信息
  • 本地项目路径 - 要部署的项目目录路径
